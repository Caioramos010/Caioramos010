# Hi there 👋

### About Me and My Professional Journey
Engenheiro de Software Full-Stack, Analista de Sistemas e criador de produtos. Minha trajetória é marcada pela entrega de soluções robustas do mundo real, unindo engenharia de automação, arquitetura de microsserviços, infraestrutura de telecomunicações e inteligência artificial. 

Com sólida vivência no desenvolvimento de ecossistemas próprios — como o **Grifa AI** e o **IlhaConecta** —, além de experiência prática sólida no setor de tecnologia e telecom, projeto sistemas de alta performance de ponta a ponta. Atuo desde a arquitetura de backend em TypeScript, Node.js, Python, Java, PHP (Laravel) e Go até ambientes conteinerizados com Docker, infraestrutura VoIP/Asterisk, bancos de dados relacionais avançados e integração de modelos de IA. Focado em código limpo, testado e escalável.
